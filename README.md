# Developer Portfolio (Static HTML/CSS/JS)

A sleek, professional portfolio with dark/light mode, reveal animations, projects, skills, experience, and contact form (demo).

## How to use
1. Unzip the folder.
2. Open `index.html` in your browser, or use VS Code Live Server.
3. Replace text (Your Name, links, etc.) with your details.
4. Update project links and `assets/YourName_CV.pdf` with your actual CV.
5. Deploy by uploading the folder to Netlify / Vercel (as a static site) or any web host.
